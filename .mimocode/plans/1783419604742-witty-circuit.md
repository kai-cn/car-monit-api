# 大规模数据查询性能优化计划

## 背景

- **数据规模**: 3张表日增70W条，月增2000W条，未来单表达8亿级
- **查询需求**: 最近一年时间段内查询、导出、统计
- **查询条件**: 时间范围 + 通用字段全模糊查询（车牌号、管理中心、路段、路线、门架、收费站）
- **技术栈**: Spring Boot 2.4.5 + MyBatis-Plus 3.5.1 + PostgreSQL(GaussDB) + Elasticsearch 7.17.0 + Flink 1.13.2
- **ES部署**: 中大集群（3节点及以上）
- **同步方式**: Flink CDC实时同步
- **导出量级**: 单次>100万条

## 现状分析

### 当前问题
1. **全模糊查询性能差**: `like '%xxx%'` 无法使用B-tree索引，8亿级数据下全表扫描不可接受
2. **深分页问题**: `OFFSET` 深分页在大数据量下性能指数级下降
3. **导出无流式处理**: 当前导出一次性加载所有数据到内存，>100万条会导致OOM
4. **单表数据膨胀**: 无分区/归档策略，单表持续膨胀
5. **ES集成不完善**: 已有ES查询代码但索引设计和查询策略未针对全模糊优化

### 现有代码基础
- `LargeScaleQueryService.java`: 已实现基于ngram的模糊查询和滚动导出，但仅针对snapshot表
- `ElasticsearchQueryService.java`: 基于ES的基础查询服务
- `LargeScaleDataSyncService.java`: 已实现时间分片批量同步到ES
- `EsQueryService.java`: ES优先查询+DB降级（但功能较基础）

## 优化方案设计

### 方案一: ES作为主查询引擎（推荐）

#### 核心思路
所有查询类操作（分页查询、模糊搜索、统计）全部走ES，MySQL仅作为数据持久化和精确ID查询的后备。

#### 数据流
```
GaussDB(MySQL) → Flink CDC → Kafka/Pulsar → ES Index
     ↑                                                              |
     └──────── 业务写入（保持主数据源）
```

#### 查询路由策略
```java
if (存在模糊查询条件 || 时间范围超过30天) {
    路由到ES查询;
} else if (主键精确查询) {
    路由到MySQL查询;
} else {
    // 小范围精确查询也可走MySQL（带分区）
    路由到MySQL查询;
}
```

#### 模糊查询实现（以车牌号为例）
```java
// 短字符（1-2位）使用wildcard
if (value.length() <= 2) {
    boolQuery.must(QueryBuilders.wildcardQuery("platenumber.keyword", "*" + value + "*"));
}
// 中等长度（3-20位）使用ngram match
else if (value.length() <= 20) {
    boolQuery.must(QueryBuilders.matchQuery("platenumber.ngram", value));
}
// 超长字符直接keyword匹配
else {
    boolQuery.must(QueryBuilders.termQuery("platenumber.keyword", value));
}
```

```sql
-- 门架抓拍表按月分区
CREATE TABLE ods_rt_szdn_snapshot_flow_addcode (
```

### 方案三: 导出优化（>100万条）

#### 使用Elasticsearch Scroll API + 流式写入
```java
@Service
public class LargeDataExportService {

    public void exportToExcel(String taskId, ExportParams params) {
        // 1. 提交异步任务到Redis
        redisCache.setCacheObject("export:" + taskId, ExportStatus.RUNNING);

        // 2. 使用ES Scroll API分批获取
        SearchRequest searchRequest = buildExportSearchRequest(params);
        SearchResponse scrollResp = esClient.search(searchRequest, RequestOptions.DEFAULT);
        String scrollId = scrollResp.getScrollId();

        // 3. 流式写入（SXSSFWorkbook处理>100万行）
        try (SXSSFWorkbook workbook = new SXSSFWorkbook(1000);
             FileOutputStream fos = new FileOutputStream(filePath)) {

            Sheet sheet = workbook.createSheet("数据");
            int rowNum = 0;

            do {
                for (SearchHit hit : scrollResp.getHits().getHits()) {
                    // 写入行数据...
                    rowNum++;
                    if (rowNum % 10000 == 0) {
                        // 进度上报
                        updateProgress(taskId, rowNum);
                    }
                }
                // 获取下一批
                scrollResp = esClient.scroll(new SearchScrollRequest(scrollId), RequestOptions.DEFAULT);
            } while (scrollResp.getHits().getHits() != null && scrollResp.getHits().getHits().length > 0);

            workbook.write(fos);
        }

        // 4. 标记任务完成
        redisCache.setCacheObject("export:" + taskId, ExportStatus.DONE);
        // 提供下载链接（OSS/文件服务器）
    }
}
```

### 方案四: Flink CDC实时同步

#### Flink Job设计
```java
public class SnapshotFlowCDCJob {
    public static void main(String[] args) throws Exception {
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();

        // 1. 配置Debezium Source
        MySqlSource<String> mySqlSource = MySqlSource.<String>builder()
            .hostname("192.168.56.10")
            .port(5432)
            .databaseList("jl_data01")
            .tableList("jl_data01.ods_rt_szdn_snapshot_flow_addcode")
            .username("gaussdb")
            .password("OpenGauss@123")
            .deserializer(new JsonDebeziumDeserializationSchema())
            .build();

        // 2. 数据处理 + 写入ES
        env.fromSource(mySqlSource, WatermarkStrategy.noWatermarks(), "MySQL CDC")
           .map(new RichMapFunction<String, SnapshotFlowDoc>() {
               @Override
               public SnapshotFlowDoc map(String value) {
                   // 解析Debezium JSON，转换为目标文档格式
                   return parseAndTransform(value);
               }
           })
           .addSink(new ElasticsearchSink.Builder<SnapshotFlowDoc>(
               new HttpHost[]{new HttpHost("localhost", 9200)},
               new SnapshotFlowIndexRequest())
               // 批量参数：1000条/10MB/5秒
               .setBulkFlushMaxActions(1000)
               .setBulkFlushMaxSizeMb(10)
               .setBulkFlushInterval(5000)
               .build());

        env.execute("Snapshot Flow CDC Sync");
    }
}
```
