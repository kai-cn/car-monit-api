# 常见问题

## 为什么查不到某个车牌？

1. 确认车牌至少 2 个字符，且没有输入通配符。
2. 确认时间范围覆盖车辆实际通行时间；跨天请用完整日期时间。
3. 抓拍表与收费表的车牌来源不同：抓拍用 `platenumber`/`plate_norm`，收费用 `plate_core` 派生列，可能存在识别差异。
4. 省界/门架设备离线时该路段无记录，可换相邻门架或扩大时间范围。
5. 最近 5 分钟的数据可能尚未进入 ES，稍后重试或改用 GaussDB 口径导出。

## 为什么总数和导出数不一致？

列表总数来自 ES 的 `track_total_hits` 封顶计数（上限 10000），导出走 GaussDB 精确统计；两者口径不同。需要精确数量时以导出任务返回的 `totalRows` 为准。

## 能否直接导出全部数据？

导出是高风险操作，仅管理员可用，且必须由用户在界面二次确认。对话中先复述范围（表、时间、车牌、模式），用户确认后由客户端携带确认令牌发起。单次导出时间范围不超过 31 天。

## 轨迹为什么是空的？

- 轨迹表按出口时间 `extime` 分区；如果车辆尚未出口，可能还没有拟合轨迹。
- `trailpoints` 只存抓拍点，设备离线或车牌识别失败会导致点稀疏。
- 轨迹回放限制 24 小时；超过请分段查询。

## 金额字段以哪个为准？

收费流水以 `realfee`（实收）为准；没有该字段时用 `fee - discountfee`。大屏收入指标已按实收汇总，两者口径一致。退款/冲正记录会影响当日金额，需在明细中核对。

## 权限与脱敏

- 普通运营角色看到脱敏车牌（前 2 后 2）；稽查/管理员可看全量。
- 导出仅管理员；会话历史仅本人可见。
- 所有工具调用都记录审计日志（请求号、租户、用户哈希、工具、耗时、结果状态）。
