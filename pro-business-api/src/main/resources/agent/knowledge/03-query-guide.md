# 查询指南与限制

## 时间范围

- 明细查询：单次最多 31 天；未指定时默认最近 7 天。
- 轨迹回放：单次最多 24 小时；未指定时默认最近 6 小时。
- 数据质量诊断：单次最多 24 小时。
- 时间格式：`yyyy-MM-dd HH:mm:ss`、`yyyy-MM-dd`、epoch 毫秒均可；纯日期作为结束时间时取当天 23:59:59。

## 车牌

- 支持完整车牌或部分车牌（至少 2 个字符）。
- 可带颜色后缀，如 `赣B21E85_0`；颜色码 0=蓝、1=黄、2=黑、3=白、4=绿（以码表为准）。
- 查询使用 `plate_norm` 归一化字段：去空格、转大写、去颜色后缀；不要输入 `*` 通配符。

## 维度过滤

- `orgcode` 管理单位、`sectioncode` 路段、`roadcode` 道路、`gantrycode` 门架、`tollcode` 收费站。
- 维度值必须是编码，不是名称；用户给名称时先说明需要编码，或建议在前端筛选。

## 分页与结果规模

- 对话场景单页最多 50 行，最多返回 20 行给模型；总数是封顶计数（上限 10000），不是精确值。
- 深分页使用 PIT + search_after，普通对话不暴露游标。
- 超过 1 万行的需求应走导出，不要在对话中逐页拉取。

## 查询引擎

- 明细查询默认走 Elasticsearch 读别名 `*-read`；ES 不可用时按配置回退 GaussDB（legacy）。
- 轨迹点、全字段导出回 GaussDB（SoR），因为 ES 不存 `trailpoints` 与大文本字段。
- 因此同一时间范围下，列表总数（ES 封顶）与导出总行数（GaussDB 精确）可能有差异。
