- **F34** `JList` 的切分改成 `StringUtils.commaDelimitedListToStringArray` 语义：只有空串得到空数组，

- **F36** 容器级 400 复刻 Tomcat HTML 页（435 字节、`text/html;charset=utf-8`、不看 Accept），
  并把 `%2f`/`%00` 的判定范围钉准：**只看 path**，query 里的 `%2F` 不触发
  （`plateimage=http%3A%2F%2F…` 必须 200）；长度闸门（`path?query` ≤ 8075）移到
  `spring_negotiation` — `src/middleware.rs::container_rejects/tomcat_bad_request`

### 排序与 SQL（阶段9 gap）

  下 JSON 数字的单键 map 表示。此前 Rust **写得进 Redis 却读不出来**

### 性能（阶段10，接口行为不变）
