## 1. `filters2` —— 过滤值形状矩阵（8894 例）

对 30 个绑定实体的每个 Mapper 过滤字段，用真实值造 6 类变体：

| 组 | 例数 | 变体内容 | 目的 |
|---|---|---|---|
| `filters2-wild` | 1146 | 值改成 `%`、`_` | MyBatis `LIKE '%' \|\| ? \|\| '%'` 的通配语义：Java 不过滤（等价全表），`_` 只吃一个字符 |
| `filters2-space` | 1146 | 值改成 `' '`、`'  '` | **列表型字段与标量型字段的分野**：Java 的 `commaDelimitedListToStringArray(" ")` → `[" "]`，走 `IN (' ')` → 0 行；空串才是「不传」 |
| `filters2-case` | 872 | 值改大写 / 小写 | GaussDB 的 `LIKE` 大小写敏感（无 `citext`），双端必须同样 0 命中或同样命中 |
| `filters2-long` | 573 | 值截断后重复到 400 字符 | 长参数不报错、不被截断（`varchar(n)` 等值条件必然不命中） |
| `filters2-dup` | 573 | 同名参数出现两次（`f=a&f=b`） | Spring `WebDataBinder` 逗号拼接成 `a,b` 再绑定；Rust 走 `serde_urlencoded` 会当重复字段直接 400 |
| `filters2-inject` | 4584 | 8 种注入串：`'`、`1' OR '1'='1`、`%`、`_`、`%_%`、`\\`、`'; DROP TABLE x; --`、中文引号混合 | 参数化绑定后注入串只当普通字面量：两端响应一致，且 8 张表 total 不变 |

结论：修复 `space` 组（F34）后 8894/8894 逐字节一致。
其中 `trailPoints` 的大写变体是 6KB 级超长参数，正好撞 Tomcat 的请求行闸门，
用于验证 F36 的容器级 400 页面是否逐字节一致。

## 2. `dates` —— 日期参数写法矩阵（1353 例）

24 个 Java `Date` 型查询字段 × 32 种写法。写法清单：

| 序号 | 写法 | Java（`DateUtils.parseDate` + lenient `SimpleDateFormat`）结果 |
|---|---|---|
| 0–5 | `2025-09-10 12:33:00` / `… 12:33` / `2025-09-10` / `2025-9-10` / `…​.000` / `2025-09` | 前 4 种与末 1 种解析成功（`2025-9-10` 靠的是数字段贪婪，不是定宽）；`.000` 因尾部残留失败 → 条件不生效 |
| 6–11 | 同上 5 种换成 `/` 分隔 + `2025/09` | 同上 |
| 12–17 | 同上 5 种换成 `.` 分隔 + `2025.09` | 同上 |
| 18 | `2025-09-10T12:33:00` | 失败（模式里没有 `T`，且要求整串消费完）→ 条件不生效，HTTP 200 全量 |
| 19 | `1757462400000` | 失败（`yyyy` 贪婪吃掉 13 位后等不到 `-`） |
| 20 | `2025-09-10 12:33:00 `（尾空格） | **失败**：Java 不 trim，`pos.index != str.length()` |
| 21 | `  2025-09-10  `（前后空格） | **失败**：同上 |
| 22 | `2025-13-45` | 宽松进位 → 2026-02-14 → 条件生效（一般 0 行） |
| 23 | `0000-00-00` | 宽松进位 → 公元前 → 条件生效；Rust 侧把结果收敛到公元 1 年，避免 `-0001-11-30` 被 GaussDB 拒为语法错（Java 是 200） |
| 24 | `2025-09-10 25:61:61` | 宽松进位 → 次日 02:02:01 → 条件生效 |
| 25–27 | `abc` / `` / `null` | 失败 → 条件不生效 |
| 28 | `2025-09-10,2025-09-11` | 失败（逗号不是任何模式的一部分） |
| 29 | `20250910` | 失败（`yyyyMMdd` 不在 12 模式里） |
| 30 | `10-09-2025` | 宽松 + 贪婪 → 年 10、月 9、日 2025 → 条件生效 |
| 31 | `2025-09-10 12:33:00+08:00` | 失败（尾部 `+08:00` 未消费） |

另有 `dates-range` 组 41 例：同一个日期键传 3 次（两个合法值 + 一个 `zzz`），
验证「先拼接后校验」（F33）。

结果：**1312 + 41 全 PASS**。修复前是 327 例不一致，类别分布（按写法序号）：

```
22/23/24/30 → 164 例（Rust 丢条件返回全量，Java 宽松进位后过滤成 0 行 / 500）
20/21       →  62 例（Rust trim 后当成合法日期，Java 忽略条件）
range       →  41 例（Rust 400，Java 200）
10/16/25/27/28/31 → 60 例（/base/feerecords 专属：Java 恒 500，Rust 绑定阶段先 400）
```
